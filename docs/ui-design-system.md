# DeFi 指标平台 UI 设计规范（Design System）

> **适用范围**：本项目全部页面 + **未来所有项目**（Boss 2026-08-03 定稿）。
> **文档位置**：`docs/ui-design-system.md` —— 独立标准，各 PRD 直接引用。
> **核心原则**：数据为王、交互可探索（TradingView 风格）、口径永远可追溯。

---

## 1. 数值与字体规范

| 规则 | 说明 |
|---|---|
| **等宽字体** | 所有数字用 `'JetBrains Mono', monospace`（对齐可读） |
| **单位简写** | 大数：B=十亿 / M=百万 / K=千；`yFmtShort` 统一 callback |
| **负值** | 一律红色 `#e5484d` |
| **无数据** | 显示「—」而非 0（0 有语义，— 表示不可得） |
| **精度** | 金额保留 2 位简写；比率 2 位小数；PE/PS 1 位小数 + 'x' |

### 通用格式化函数（前端复用）
```js
const moneyFmt = v => v == null ? '—' : '$' + (v >= 1e9 ? (v/1e9).toFixed(2)+'B' : v >= 1e6 ? (v/1e6).toFixed(2)+'M' : v >= 1e3 ? (v/1e3).toFixed(1)+'K' : v.toFixed(0));
const yFmtShort = v => v == null ? '—' : (Math.abs(v) >= 1e9 ? (v/1e9).toFixed(1)+'B' : Math.abs(v) >= 1e6 ? (v/1e6).toFixed(1)+'M' : Math.abs(v) >= 1e3 ? (v/1e3).toFixed(1)+'K' : v.toFixed(0));
```

## 2. 页面区块规范

### 2.1 关键注意事项（Caveats）
- **可折叠卡片**：`<details>/<summary>`，默认收起，点击展开
- 字体 12px（比正文小一号），减少视觉噪音
- 颜色：橙色系（警示语义）

### 2.2 损益表（瀑布式）
- **三个节点**：收入 → 毛利 → 净利，**SVG 箭头连接线**串起流向
- 每节点卡片含：指标名 + 大数字（等宽字体）+ **边际率小字** + ⓘ 可展开计算过程
- 净利为负时红色
- 平台币口径：毛利 = 净利 = 收入（无 LP 成本模型）

### 2.3 历史数据图表（TradingView 风格，核心）
- **单图表叠加**：柱状（单日净收益，左轴）+ 折线（TTM 累计总量，右轴），不拆双图
- **标签定名（Boss 定稿）**：
  - 折线 = **TTM 累计总量**（过去 365 天滚动和：每天加新增一期、减掉超过一年那期）
  - 柱状 = **单日净收益**（当天统计到的值）
  - 其他指标切换时：折线切换该指标，柱状保持单日净收益
- **交互**（chartjs-plugin-zoom v2）：
  - 拖动平移（pan mode='x'）、滚轮缩放（wheel）、框选时间范围（drag mode='x'）、双击重置
  - **⚠️ 配置结构铁律**：`plugins.zoom = { pan: {...}, zoom: { wheel, pinch, drag, mode } }` —— pan 和 zoom.zoom 必须并列，错误结构不报错但交互全部失效
- **坐标轴**：
  - 纵坐标简写（B/M/K）
  - 横坐标完整日期（2025-08-03），Chart.js autoSkip 自动选 tick
- **高度限制**：单日净收益柱状最高点 ≤ 图 1/2 高度（`y.max = p90 × 2.2`，用 p90 避免异常日拉爆）
- **数据密度**：一天一个点，不稀疏采样（数据 <2000 条时 Chart.js 都能渲染）
- **口径一致**：折线最新点必须 = 损益表净收益（同 net_income 字段），用户可对照

### 2.4 代币流通量
- Hero 区：当前流通量**大数字**（橙色 #f0b90b，38px）+ 日期/符号/精确枚数
- 下方历史曲线：90 天每日流通量（CMC historical API），同样支持拖动/缩放/简写
- 说明文案：流通量随时间变化反映增发 vs 销毁净效果

### 2.5 指标切换按钮
- **放在图表下方**（不放上方）
- pill 风格：圆角胶囊（border-radius: 20px），active 绿色高亮（rgba(34,197,94,0.12) 底 + accent 边框）

## 3. 颜色规范

| 语义 | 颜色 | 用途 |
|---|---|---|
| 单日净收益 / 主指标 | `#22c55e`（绿） | 柱状、positive 值 |
| TTM 累计总量 | `#f59e0b`（橙） | 折线、右轴 |
| BNB 流通量 | `#f0b90b`（金） | 流通量 Hero/曲线 |
| 负值 | `#e5484d`（红） | 负净利等 |
| 中性 | `#71717a` | 坐标 tick、辅助文字 |

> 注意：**折线（TTM）与柱状（单日）必须不同色系**（橙 vs 绿），图例可区分。

## 4. 数据更新与渲染规范

- **`.chart-section { display: none }`** 默认隐藏，JS 渲染成功后加 `.has-data` class 才显示（新增图表区块必加）
- 历史数据：**一天一个点**，每日快照累积；Auto-Burn 等季度事件按区间均摊（不堆单月）
- 口径标注：图表 y 轴/图例/tooltip 全链路用同一命名（TTM 累计总量 / 单日净收益），与损益表字段一一对应
