## ⚖️ 全局铁律（Boss 逐一定稿，所有协议通用）

1. **只计流向流通持币人的价值流**（PRD 三大铁律之一）
2. **🆕 销毁未流通量不计入（Boss 2026-08-04 定稿）**：
   平台币/公链币的销毁，**若销毁的是未流通量（未解锁/锁仓/储备/团队部分），不计入回购（Buyback Yield）也不计入股东回报（Shareholder Yield）**——
   因为未流通量从未流向市场，销毁它们不产生「流向流通持币人的价值流」，对持币人无实际回报意义。
   - **判断标准**：销毁对象是**流通供应**（可在市场自由交易的币）→ 计入；是**未流通供应**（锁仓/储备/未解锁）→ 不计入
   - **示例**：Aster「1:1 储备销毁」不计入（未流通币）；BNB Auto-Burn / BEP-95 销毁流通币 → 计入
3. **增发成本配比原则**：有对价换收入 → 成本；无对价 → 稀释注记
4. **所有计算用净利润**
5. **收入 → 毛利 → 净利 → 股东回报 → 留存** 五段式，只展示不造假
